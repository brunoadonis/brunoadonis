Analista de Dados com foco em desenvolvimento de soluções orientadas a dados, automação de processos, engenharia de dados e construção de pipelines analíticos.

Tenho experiência com análise, transformação e integração de dados, atuando com tecnologias como Python, SQL, PySpark, Delta Lake e arquitetura Lakehouse.
